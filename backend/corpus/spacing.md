# Spacing System

## Base Unit
4px base unit. All spacing should be multiples of 4.

## Scale
| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline element gaps |
| sm | 8px | Related element spacing |
| md | 16px | Component internal padding |
| lg | 24px | Section spacing |
| xl | 32px | Major section breaks |
| 2xl | 48px | Page-level spacing |

## Component Padding
- Buttons: 12px vertical, 16px horizontal
- Input fields: 12px all sides
- Cards: 16px or 24px
- Modals: 24px

## Rules
- Always use consistent spacing within a component
- Maintain visual rhythm with consistent vertical spacing
- Use larger spacing to separate distinct content groups
