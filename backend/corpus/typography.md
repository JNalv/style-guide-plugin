# Typography Guidelines

## Font Family
- Primary: Inter
- Monospace: JetBrains Mono (code only)

## Type Scale
| Name | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Display | 48px | Bold (700) | 1.2 | Hero headings |
| H1 | 32px | Bold (700) | 1.3 | Page titles |
| H2 | 24px | SemiBold (600) | 1.4 | Section headings |
| H3 | 20px | SemiBold (600) | 1.4 | Subsection headings |
| Body | 16px | Regular (400) | 1.5 | Paragraph text |
| Body Small | 14px | Regular (400) | 1.5 | Secondary text |
| Caption | 12px | Medium (500) | 1.4 | Labels, hints |
| Overline | 10px | Bold (700) | 1.2 | Category labels |

## Rules
- Never use font sizes outside this scale
- Maintain consistent line heights
- Use sentence case for headings (not Title Case)
- Maximum line length: 75 characters for body text
