# Component Guidelines

## Buttons

### Primary Button
- Background: Primary 500 (#2563EB)
- Text color: White (#FFFFFF)
- Padding: 12px vertical, 16px horizontal
- Border radius: 6px
- Font: Inter, 14px, Medium (500)
- Hover: Primary 600 (#1D4ED8)

### Secondary Button
- Background: Transparent
- Text color: Primary 500 (#2563EB)
- Border: 1px solid Primary 500
- Padding: 12px vertical, 16px horizontal
- Border radius: 6px
- Font: Inter, 14px, Medium (500)

## Input Fields
- Background: White (#FFFFFF)
- Border: 1px solid Gray 200 (#E5E7EB)
- Border radius: 6px
- Padding: 12px all sides
- Font: Inter, 16px, Regular (400)
- Placeholder: Gray 500 (#6B7280)
- Focus: Border color Primary 500 (#2563EB)

## Cards
- Background: White (#FFFFFF)
- Border: 1px solid Gray 200 (#E5E7EB)
- Border radius: 8px
- Padding: 16px or 24px
- Shadow: Subtle elevation (optional)

## Rules
- Maintain consistent component styling across the design
- Use semantic colors for states (success, warning, error)
- Ensure interactive elements have clear hover states
- Maintain proper spacing between related components
